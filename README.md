# قالب موقع أكاديمي شخصي — GitHub Pages

هذا قالب موقع شخصي باللغة الإنجليزية، مبني على HTML وCSS فقط. لا يحتاج إلى قاعدة بيانات أو إطار عمل، ويمكن نشره مجانًا باستخدام GitHub Pages.

## 1) قبل النشر: عدّل المعلومات

افتح `index.html` في محرر نصوص، أو اضغط على الملف داخل GitHub ثم زر القلم (Edit this file). ابحث عن النصوص الموجودة بين الأقواس المربعة `[...]` واستبدلها بمعلوماتك الحقيقية، خصوصًا:

- `[Your Name]`: اسمك بالطريقة التي تريد عرضها مهنيًا.
- `YN`: الأحرف الأولى من اسمك في العلامة المربعة.
- `[Your academic role or professional headline]`: وصف دقيق لوضعك الحالي، من دون استخدام لقب لم تحصل عليه.
- `[Research theme one]` وما شابه: اهتماماتك البحثية الفعلية.
- نصوص السيرة الذاتية والمشاريع والأنشطة: أضف المعلومات التي تستطيع تأكيدها فقط.
- `your.email@example.com`: بريدك المهني، في كل موضع يظهر فيه.
- `YOUR-USERNAME`: اسم مستخدم GitHub الخاص بك.
- وصف الموقع داخل `meta name="description"` وقيمة `meta name="author"` في أعلى الملف.

إذا لم تكن لديك منشورات علمية منشورة، لا تخترع منشورات. يمكنك حذف قسم المنشورات مؤقتًا أو إبقاء رسالة القالب أثناء التعديل، لكن احذف الرسالة الإرشادية قبل إطلاق الموقع للعامة. أضف رابط DOI أو رابط الناشر بعد التحقق منه فقط.

## 2) إنشاء حساب ومستودع الموقع

1. أنشئ حسابًا على https://github.com/ إذا لم يكن لديك حساب.
2. اختر اسم مستخدم مهنيًا مختصرًا قدر الإمكان. عنوانك المجاني سيعتمد عليه، لذا فكّر فيه قبل تثبيته.
3. أنشئ مستودعًا جديدًا (New repository) باسم مطابق تمامًا لاسم المستخدم متبوعًا بـ `.github.io`.
   - مثال: إذا كان اسم المستخدم `sample-name` فاسم المستودع هو `sample-name.github.io`.
4. اجعل المستودع `Public` إذا كنت تستخدم GitHub Free، وأضف ملف README إن ظهر الخيار.
5. فك ضغط ملف القالب على جهازك. ارفع **محتويات المجلد** إلى جذر المستودع، بحيث يكون `index.html` ظاهرًا مباشرة في الصفحة الرئيسية للمستودع، وليس داخل مجلد فرعي إضافي.

## 3) رفع الملفات من المتصفح

داخل مستودع GitHub:

1. اختر **Add file → Upload files**.
2. اسحب `index.html` و`.nojekyll` و`README.md` إلى منطقة الرفع. إذا لم تتمكن من تحديد الملف المخفي `.nojekyll`، فهو اختياري في هذا القالب.
3. في الأسفل اضغط **Commit changes**.

## 4) تفعيل GitHub Pages

1. افتح **Settings** داخل المستودع.
2. من القائمة الجانبية اختر **Pages**.
3. في **Build and deployment**، اختر **Deploy from a branch**.
4. اختر الفرع `main` والمجلد `/(root)`، ثم اضغط **Save**.
5. افتح `https://YOUR-USERNAME.github.io` بعد اكتمال النشر. قد يحتاج ظهور التعديلات إلى عدة دقائق.

مرجع GitHub الرسمي: https://docs.github.com/en/pages/quickstart

## 5) تحديث الموقع لاحقًا

افتح `index.html` في المستودع، اضغط زر القلم لتعديله، ثم اختر **Commit changes**. سيعيد GitHub Pages نشر التغييرات تلقائيًا.

لإضافة سيرة ذاتية PDF، ارفع ملفًا باسم `cv.pdf` إلى جذر المستودع، ثم عدّل قسم السيرة الذاتية في `index.html` لإضافة رابط مثل `<a href="cv.pdf">Download my CV (PDF)</a>`.

## 6) قائمة تحقق قبل النشر

- [ ] استبدال كل النصوص الإرشادية والمعلومات بين الأقواس المربعة.
- [ ] استبدال البريد الإلكتروني واسم مستخدم GitHub التجريبيين.
- [ ] حذف الأقسام التي لا تنطبق عليك.
- [ ] التحقق من كل رابط قبل النشر.
- [ ] عدم نشر بيانات خاصة، مثل عنوان المنزل أو رقم الهاتف الشخصي أو أي معلومات لا تريد أن تكون متاحة للعامة.
- [ ] عدم وصف بحث أو مقال بأنه منشور قبل التحقق من حالته ومصدره.

## الملفات

- `index.html`: الموقع الكامل وتصميمه المتجاوب.
- `.nojekyll`: ملف فارغ اختياري يساعد GitHub Pages على تقديم الملفات الثابتة دون معالجة Jekyll.
- `README.md`: هذا الدليل.
